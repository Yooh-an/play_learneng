# Chrome 웹 스토어 스크린샷 가이드

## 📸 필요한 스크린샷 (최소 1개, 최대 5개)

### 1. 메인 기능 스크린샷 (필수)
- **크기**: 1280x800 또는 640x400
- **내용**: Coupang Play에서 이중 자막이 표시된 화면
- **포함 요소**:
  - 한글 자막 (상단)
  - 영어 자막 (하단)
  - 자막 배경 효과
  - Coupang Play 비디오 플레이어

### 2. 설정 팝업 화면
- **크기**: 640x400
- **내용**: 확장 프로그램 팝업 설정 화면
- **포함 요소**:
  - 폰트 크기 슬라이더
  - 위치 조정 슬라이더
  - 배경 투명도 슬라이더
  - 한국어 라벨

### 3. 자막 크기 조정 시연
- **크기**: 1280x800
- **내용**: 자막 크기가 다른 before/after 비교
- **설명**: "자막 크기를 10px~30px로 자유롭게 조정"

### 4. 자막 위치 조정 시연
- **크기**: 1280x800
- **내용**: 자막 위치가 다른 before/after 비교
- **설명**: "화면 상단부터 하단까지 위치 조정 가능"

### 5. 배경 투명도 효과
- **크기**: 1280x800
- **내용**: 배경 투명도가 다른 상태 비교
- **설명**: "텍스트 가독성을 위한 배경 투명도 조절"

## 📝 스크린샷 촬영 팁

1. **고화질**: 선명하고 깔끔한 이미지
2. **현실적**: 실제 사용 상황을 보여주는 화면
3. **명확성**: 기능이 명확히 보이도록 촬영
4. **일관성**: 동일한 비디오 콘텐츠 사용 권장

## 🎨 권장 촬영 설정

- Coupang Play에서 인기 영화/드라마 선택
- 자막이 잘 보이는 장면 선택
- 확장 프로그램 기능을 명확히 보여주는 설정 사용
- 깔끔한 브라우저 환경 (북마크 바 숨김 등)

## 📁 파일 형식
- **지원 형식**: PNG, JPEG
- **권장 형식**: PNG (더 선명함)
- **파일 크기**: 각 파일 최대 10MB
