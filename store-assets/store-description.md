## 설명

### 간단한 설명 (132자 제한)
Coupang Play에서 한영 이중 자막으로 외국어 학습을 도와주는 확장 프로그램

### 상세 설명
Coupang Play에서 영어 학습을 위한 완벽한 도구입니다!

🎯 주요 기능:
• 한글/영어 이중 자막 동시 표시
• 자막 크기 실시간 조정 (10px~30px)
• 자막 위치 자유롭게 조정 (화면 상단~하단)
• 배경 투명도 조절 (0%~100%)
• 텍스트 영역에만 배경 적용
• 향상된 가독성을 위한 시각 효과

🔧 사용법:
1. Coupang Play에서 영상 재생
2. 확장 프로그램 아이콘 클릭
3. 원하는 설정으로 자막 커스터마이징
4. 편안한 환경에서 언어 학습!

✨ 특징:
- 실시간 설정 변경
- 깔끔한 UI/UX
- 높은 성능과 안정성
- 한국어 인터페이스 지원

영어 학습의 새로운 경험을 시작해보세요!

## 권한 사용 설명
- **Storage**: 사용자 자막 설정을 로컬에 저장하기 위해 사용
- **Tabs**: Coupang Play 페이지 감지를 위해 사용
- **Host permissions**: Coupang Play 사이트에서만 자막 기능을 제공하기 위해 사용

모든 권한은 확장 프로그램의 핵심 기능 제공을 위해서만 사용됩니다.
